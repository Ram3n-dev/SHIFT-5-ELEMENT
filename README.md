# Енотономика

Финансовый помощник для студентов со стипендией. Отвечает на вопрос **«сколько можно тратить, чтобы дотянуть до стипендии»**, подбирает категории кэшбэка под реальные траты и объясняет, куда уходят деньги.

Главный принцип: **числа считает код, ИИ только объясняет готовый расчёт**. Ответы Енота — ориентир, а не финансовая рекомендация: он не советует кредиты, займы, рассрочку, инвестиции и вклады.

## Что умеет

- **Онбординг по одному вопросу на экран**: город (для цен региона), стипендия и её число, деньги сейчас, обязательные траты, резерв, период лимита. В конце Енот пересчитывает деньги и показывает лимит.
- **Гибкий лимит**: на день, 3 дня или неделю — переключается на главной в один тап.
- **Огонёк** — серия дней в пределах лимита, как в Duolingo. Заморозка раз в 7 дней, кнопка «Сегодня без трат».
- **Проверка покупки**: как покупка изменит дневной лимит.
- **Анализ трат**: куда уходят деньги, сравнение с прошлым периодом, «лишние» траты.
- **Енот (ИИ-чат)** с готовыми подсказками: почему такой лимит, почему деньги кончаются быстрее, как дотянуть, где лишние траты, какой кэшбэк выбрать и др.
- **Подбор кэшбэка**: скриншот категорий из банка (распознаётся в браузере) или ввод вручную → код считает выгоду по тратам → Енот объясняет → итоги месяца: сколько кэшбэк принёс на самом деле.
- **Партнёрские предложения** с напоминанием, когда срок подходит к концу.
- **Цены региона**: минимальный набор продуктов по данным Росстата.
- **Напоминания Енота** — не больше двух в день, внутри приложения или уведомлением браузера.
- **Вход через Google** и демо-вход, баннер cookie, светлая и тёмная тема, версии для телефона и компьютера.

## Запуск в Docker

```bash
cp .env.example .env      # заполнить ключи Google и RouterAI (необязательно)
docker compose up --build
```

Приложение: http://localhost:8080. Без ключей работают демо-вход и ответы Енота по шаблонам.

## Запуск без Docker (Windows)

1. Установить инструменты (PowerShell):

   ```powershell
   winget install Git.Git
   winget install Microsoft.DotNet.SDK.10
   winget install OpenJS.NodeJS.LTS
   winget install --id PostgreSQL.PostgreSQL.17 --exact
   ```

   PostgreSQL из winget ставится с пользователем `postgres` и паролем `postgres` на порту 5432. Если ставили установщиком с сайта — используйте пароль, который задали. Если скачанный установщик не запускается из браузера, откройте папку «Загрузки» и запустите файл двойным щелчком.

2. Создать базу:

   ```powershell
   & "C:\Program Files\PostgreSQL\17\bin\psql.exe" -U postgres -c "CREATE DATABASE limitplus;"
   ```

3. Создать `backend/LimitPlus.Api/appsettings.Local.json` (в git не попадает):

   ```json
   {
     "ConnectionStrings": { "Default": "Host=localhost;Port=5432;Database=limitplus;Username=postgres;Password=postgres" },
     "Google": { "ClientId": "", "ClientSecret": "" },
     "Llm": { "Enabled": true, "ApiKey": "ключ RouterAI" }
   }
   ```

4. Запустить backend и frontend в двух окнах:

   ```powershell
   cd backend; dotnet run --project LimitPlus.Api
   ```

   ```powershell
   cd frontend; npm install; npm run dev
   ```

Приложение: http://localhost:5173. Таблицы и цены регионов backend создаёт сам при запуске. Если есть Docker, базу можно поднять одной командой `docker compose up -d db` — тогда подойдут настройки из `appsettings.json` (порт 5433) и файл Local нужен только для ключей.

## Вход через Google

1. [Google Cloud Console](https://console.cloud.google.com/) → создать проект → **Google Auth Platform**: название приложения, почта, аудитория «External». Пока приложение в режиме тестирования, добавьте свои Google-аккаунты в тестовые пользователи.
2. **Clients → Create client → Web application**. Authorized redirect URIs:
   - `http://localhost:8080/signin-google` — Docker;
   - `http://localhost:5173/signin-google` — разработка (`npm run dev`).
3. Client ID и Client secret — в `.env` (`GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`) или в секцию `Google` файла `appsettings.Local.json`.

Пароль и токены Google не сохраняются: после входа браузер получает только cookie `lp_auth` (HttpOnly).

## ИИ (RouterAI)

Настройки — секция `Llm` (`BaseUrl`, `Model`, `ApiKey`) или переменные `LLM_*` в `.env`. Ключ хранится только на сервере и в браузер не попадает; файлы `.env` и `appsettings.Local.json` исключены из git.

Как отвечает Енот:

1. Код считает факты: лимит, траты по категориям, сравнение периодов, подбор кэшбэка — и собирает шаблон ответа.
2. Модель пересказывает шаблон живым языком (температура 0.3).
3. Ответ проверяется: не длиннее 120 слов, нет новых чисел, нет тем про кредиты, займы, рассрочку, инвестиции и вклады. Не прошёл проверку, ИИ выключен или недоступен — показывается шаблон.

## Сценарий для показа

1. «Попробовать без регистрации» → «Заполнить примером» (или ответить на вопросы онбординга).
2. «Операции» → «Импорт CSV» → `demo-data/student_2_months.csv` на «Карту». Переключатель «Баланс уже учитывает эти операции» оставить включённым.
3. Главная: лимит, переключатель «День / 3 дня / Неделя», огонёк и «Сегодня без трат», цены региона, «Хочу купить».

7. «Профиль» → тёмная тема; открыть сайт на компьютере и телефоне.

## Как считается

**Лимит** (`Logic/BudgetCalculator.cs`)

```
дней до стипендии = дата стипендии − сегодня      (сегодня считается, день стипендии — нет)
обязательные      = осталось оплатить в этом периоде + регулярные платежи до стипендии
свободно          = балансы счетов «в лимите» − обязательные − резерв
лимит дня         = ⌊(свободно на начало дня) / дней до стипендии⌋
лимит на 3 дня / неделю = лимит дня × min(3 или 7, дней до стипендии)
```

Сегодняшние траты уже «внутри» лимита дня: перерасход уменьшает лимит на следующие дни, экономия — увеличивает. Статус: лимит от 200 ₽ — норма, меньше — напряжённо, 0 — свободных денег нет.

**Покупка**: лимит пересчитывается так, будто покупка уже сделана. Лимит падает на 20% и больше — предупреждение; денег после обязательных трат и резерва не остаётся — «лучше отложить».

**Огонёк** (`Logic/StreakCalculator.cs`): день засчитан, если отмечен (есть записи или «Сегодня без трат») и траты не больше лимита дня. Перерасход обнуляет серию. Один пропуск раз в 7 дней закрывает заморозка. Сегодняшний неотмеченный день серию не рвёт.

**Кэшбэк** (`Logic/CashbackOptimizer.cs`): траты картой за 90 дней пересчитываются на месяц; перебираются все наборы из 4 категорий; на одну категорию трат действует больший процент; сумма за месяц не больше 3 000 ₽. Итоги месяца сравнивают выбор с лучшим возможным набором и с «1% на всё».

**Анализ трат** (`Logic/SpendingAnalyzer.cs`): первые N дней текущего периода сравниваются с теми же N днями прошлого. «Лишние» траты: 4 и больше раз в одной необязательной категории за неделю, 5 и больше мелких покупок до 300 ₽, дни сверх лимита.

**Напоминания** (`Logic/NotificationPlanner.cs`): вечером, если день не отмечен; серия под угрозой; перерасход; день стипендии и за 3 дня до неё; выбор кэшбэка в конце месяца; конец партнёрского предложения. Не больше двух в день, без сумм в тексте.

## Цены регионов

`backend/LimitPlus.Api/Data/regional-prices.csv` — стоимость минимального набора продуктов по данным Росстата за июль 2026 года (по публикациям [«Руспродсоюза» / ТАСС](https://finance.mail.ru/article/rusprodsoyuz-minimalnaya-produktovaya-korzina-zametno-podorozhala-69225409/) и [НГС](https://ngs.ru/text/food/2026/08/13/76587098/)). Для регионов без данных показывается среднее по России.

Формат: `region_code;region_name;food_basket_month;period;source`. Чтобы обновить цены, замените строки в файле — при запуске backend перезапишет их в базе.

## Учебная выписка CSV

```
date,description,amount,category
2026-09-25,Стипендия,5000,Стипендия
2026-09-26,Шаурма у общаги,-190,Кафе и доставка
```

`amount > 0` — доход, `< 0` — трата. Файл разбирается в браузере, на сервер уходят только готовые операции. Категории трат: Продукты, Кафе и доставка, Транспорт, Такси, Учёба, Связь, Подписки, Здоровье, Развлечения, Одежда, Другое; доходов: Стипендия, Подработка, Перевод, Другое. `demo-data/broken_example.csv` показывает, как выводятся ошибки.

## API

Все запросы — `/api/...`, JSON в snake_case, вход по cookie. Изменяющие запросы должны идти с заголовком `X-Requested-With: limitplus` (защита от CSRF). Браузер передаёт свою дату и час (`X-Local-Date`, `X-Local-Hour`), потому что сервер может жить в другом часовом поясе. Готовые примеры — в `backend/LimitPlus.Api/LimitPlus.Api.http`.

| Группа | Запросы |
|---|---|
| Вход | `GET auth/config`, `GET auth/google`, `POST auth/demo`, `POST auth/logout` |
| Профиль | `GET me`, `POST onboarding`, `PUT profile`, `DELETE profile`, `GET regions` |
| Главная | `GET dashboard`, `POST purchase-check`, `GET analytics`, `POST day/no-spend`, `POST stipend/received` |
| Деньги | `accounts`, `operations`, `POST operations/import`, `recurring`, `POST recurring/{id}/paid` |
| Кэшбэк | `GET cashback/{yyyy-MM}`, `PUT …/options`, `POST …/choose`, `GET …/results`, `partner-offers` |
| Енот | `GET ai/prompts`, `GET/DELETE ai/history`, `POST ai/chat` |
| Прочее | `GET notifications`, `POST notifications/{key}/shown`, `POST consent`, `POST events`, `GET health` |

## Данные и безопасность

- Только учебные данные: не вводите реальные пароли банков, коды из SMS, CVV и полные номера карт. Пароль входа в Енотономику хранится только как хеш. Учебная выписка из песочницы банка разбирается на сервере: после разбора остаются сумма, дата, категория и описание, без номеров счетов, ИНН, карт и ФИО. Приложение не проводит операций с деньгами.
- В базе хранится то, что пользователь ввёл сам, выбор кэшбэка, переписка с Енотом и согласия. «Удалить мои данные» в профиле стирает всё сразу; демо-профили удаляются через 7 дней.
- Скриншоты и CSV обрабатываются в браузере. В ИИ уходят вопрос и рассчитанные цифры — без имени и почты.
- Cookie: `lp_auth` (вход), `.AspNetCore.Correlation.*` (защита входа Google), `lp_consent` (выбор в баннере). Статистика экранов отправляется только после «Разрешить всё».

## Ограничения

- Расчёт — ориентир, а не финансовая рекомендация.
- Категории кэшбэка и партнёрские предложения пользователь переносит из приложения банка сам (скриншотом или вручную): открытого API кэшбэка у банков нет, а парсинг сайтов запрещён их правилами.
- Цены Росстата есть не для всех регионов — для остальных берётся среднее по России.
- Напоминания приходят, пока сайт открыт в браузере: отдельного push-сервера нет.
- Регулярный платёж учитывается один раз до стипендии.
